# 交付前质量检查

出图后逐项核对，全部通过再交付。

## 数据正确性

- [ ] 只绘制了用户提供/确认的数据；未补点、删点、改误差或"美化"趋势。
- [ ] 轴范围合理，异常值保留或已获用户确认剔除。
- [ ] 数值与来源一致；单位正确、量纲自洽。
- [ ] 图例/标签与数据序列一一对应，无张冠李戴。

## 可读性（按目标尺寸检查）

- [ ] 缩放至最终宽度（85 或 180 mm）后，最小文字仍 ≥ 6 pt 等效、清晰不糊。
- [ ] 面板字母、轴标签、刻度、图例层级分明，无重叠、无裁切。
- [ ] 颜色非唯一编码；叠加线型/标记或直接标签。
- [ ] 热图有色条与色条标签；连续/发散选择正确。
- [ ] 灰阶电镜图有白色标尺与必要的假彩元素图及颜色键。

## 出版规格

- [ ] 输出含 PNG（600 dpi）、SVG、PDF；JSON/脚本源文件保留。
- [ ] 文字为矢量（SVG 未转轮廓、PDF 字体已嵌入）。
- [ ] 背景纯白、无多余边框；出血与页边距留白足够。
- [ ] 中文字体已正确嵌入，无乱码、无豆腐块。

## 风格一致

- [ ] 全图 ≤ 4 主色；同一样品/条件各面板颜色一致。
- [ ] 面板间距、字号、线宽统一。
- [ ] 无 3D 柱状图、饼图、彩虹热图、装饰性渐变等反例。
